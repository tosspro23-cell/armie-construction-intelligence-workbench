not a claim of authorship. See `docs/reports/2026-09-15-dataset-pack-go-no-go-spike.md` for the

considered (WBDG Office, Sixty5).

No companion PDF schedule exists for this building in the source repository (confirmed via the
full repository file listing) -- `digitalhub_schedule.pdf` is synthetic, ARMIE-generated by
`scripts/generate_digitalhub_schedule.py`, not a real document. Its Mark column uses this file's
own real IFC `Tag` values and its Level/Type/Width/Height columns are the real IFC quantities for
every entry except four deliberately planted discrepancies (documented in full in that script's
own header and D-036): one real door omitted entirely (`missing_in_pdf`), one fabricated row with
no matching real IFC element (`missing_in_ifc`), and two real doors/windows with an altered width
or height (`dimension_mismatch`) -- exactly the same fixture-design pattern SPEC-M2's original
synthetic schedule used, just at real-building scale (111 real openings instead of 9).
