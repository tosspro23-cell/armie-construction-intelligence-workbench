Apartment project was first published in Germany and provided to the US Construction

Building Sciences from 2009 thru 2020, but were taken down without notice and so have been

that GitHub URL. This file is used here for reference/portfolio purposes under those terms --
not a claim of authorship.

This is a real, two-story duplex apartment building (twin residential units), used as the
second real-building Dataset Pack candidate specifically for its clearly residential room
layout (Bedroom 1/2, Bathroom 1/2, Kitchen, Living Room, Foyer, Hallway, Utility, Stair --
confirmed by reading the model's own `IfcSpace` names directly). It has no garage, pool, or
yard/deck (also confirmed directly, not assumed) -- a genuinely villa-scale building with those
amenities under a clean open license could not be found in the public IFC test-file ecosystem.

No companion PDF schedule exists for this building in the source repository (only Bill of
Quantities spreadsheets and manufacturer product-data sheets, neither of which is a door/window
schedule) -- `duplex_schedule.pdf` is synthetic, ARMIE-generated by
`scripts/generate_duplex_schedule.py`, using this file's own real IFC `Tag` values and real
dimensions (falling back to `OverallWidth`/`OverallHeight` where no `IfcElementQuantity` set is
attached, exactly matching D-037's application-code fix -- this file's doors/windows have no Qto
set at all, the same gap found on the WBDG Office candidate during the original go/no-go spike),
correct for every entry except a small number of deliberately planted discrepancies documented
in that script's own header.
